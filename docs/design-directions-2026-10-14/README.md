# 视觉方向提案 · 2026-10-14

本轮交付为三个静态概念图，供选择整体视觉方向。它们不是已运行网页，也不是已实现交互的截图。现有已发布版本未替换。

## A 创作控制台
最接近用户提供的参考：蓝色线框切分、红蓝人物、大字、紧凑状态栏。
拟实现：底部滑杆控制人物插画的轻微动作幅度；分类按钮切换同框作品；标题与分割线采用短过渡。
字体：紧凑粗无衬线英文标题 + 清晰中文黑体。人物最终依据用户自拍重新定制。

## B 编辑手记
以衬线斜体大字、中文黑体、蓝色网格和手绘注记形成杂志感。
拟实现：作品单元原地展开为案例，其他单元收窄；左右翻阅；保留全部已有图集、视频和案例。

## C 构建者桌面
以带编号的纸片、插画与连接线呈现插件、工作流、Skill、Agent。
拟实现：纸片可拖动、选择后置顶；一键整理恢复位置；点选打开案例。手机端采用可点击的顺序布局，避免依赖拖动。

## 实现约束
- 图片只用于选方向，正文、导航、线框与操作按钮使用真实 HTML/CSS。
- 插画作为独立素材，不把整张概念图贴成网站。
- 保留已经恢复的所有案例、图片、视频和实际截图。
- 动效尊重 reduced-motion；键盘与触屏均可操作。
- 概念图内新增装饰性文案与人物均为示意，落地时核对真实内容。
