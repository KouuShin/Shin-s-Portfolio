Palette study / personal website upgrade

透亮、高清、平和，但不平。

这页不是最终设计稿，而是三种视觉语言的色卡和案例感预览。请重点看： 亮色是否高级、留白是否舒服、字体和版式是否有你说的那种平衡感。

暖白纸感
Bright Editorial

高级画册 温和 适合个人叙事 最透亮

01

AI 明检
销售能力评估系统

把传统人工明检升级为 AI 对话式考核，从任务配置、角色权限、语音实战到个性化报告形成训练闭环。

01大标题像书籍封面，图片和文字都安静地落在网格里。
02适合放你的个人经历、设计思考、项目浓缩故事。
03风险是如果图片质量不够，页面会显得太素，需要靠排版撑住。
关键词：warm white / art book / quiet luxury / editorial grid 适合：想让个人网站更像设计作品集画册。
Direction B

黑白灰网格
Sharp Neutral

最克制，也最考验比例。亮色只作为标记、编号、悬停状态出现， 主体靠强字体、强对齐和图像大小关系制造高级感。

设计师感 理性 强排版 不容易土

02

Curiosity
as System

页面像一套可翻阅的档案：个人介绍、时间线、项目案例用统一编号系统串起来。

01视觉重点靠字号反差、编号、细线和图片比例，不靠装饰。
02适合突出你的产品分析、AI 工作流、需求文档能力。
03风险是会更冷，需要用个人照片或一两个温暖细节补人味。
关键词：Swiss grid / monochrome / acid accent / disciplined spacing 适合：想让作品集看起来最专业、最耐看。
Direction C

深色透光
Luminous Dark

保留你现在的深色基因，但去掉平面感。亮色像屏幕光、玻璃反射和夜间展厅， 不是霓虹堆叠，也不是紫蓝渐变。

沉静 科技但不俗 适合 AI 项目 延续现有气质

03

Dialogue
Evaluation

用更深的黑、更干净的白和少量暖光，承载 AI 明检、Synapse 等项目的技术叙事。

01适合做滚动中的光影层次、截图玻璃感、项目详情弹窗。
02比现在更高级的关键：减少彩色雾化背景，增加排版秩序。
03风险是如果光效太多，会回到“网页特效感”，要克制。
关键词：luminous dark / glass light / editorial tech / quiet AI 适合：想保留神秘感，同时让页面更活。
